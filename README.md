# sbrt.in — Society for Bacteriophage Research and Therapy

Static website of SBRT India, served by GitHub Pages.
Every page is a single self-contained HTML file (styles, scripts, images embedded),
so the site needs no build step: what is in this repository is what goes live.

- Live: https://www.sbrt.in
- Update: overwrite any `.html` here (Add file → Upload files) or `git push` — Pages republishes in ~1 minute.
- Source of truth for edits: see EDITING-GUIDE (kept with the society's master copy).
